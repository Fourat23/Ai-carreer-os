# Ressources

Ressources sélectionnées, majoritairement **gratuites** et de qualité. Règle : une ressource ne remplace jamais la pratique. Lis peu, code beaucoup.

## Fondations (mois 1-2)
- **MDN Web Docs** (developer.mozilla.org, en français) — LA référence JavaScript. Garde-la ouverte toute l'année.
- **javascript.info** — cours JS moderne, clair, progressif (existe en français).
- **learngitbranching.js.org** — apprendre Git interactivement (gratuit).
- **The Linux Command Line** (livre gratuit en ligne) — le terminal en profondeur.
- **Grafikart** (français, YouTube) — excellentes vidéos JS/web gratuites.
- **freeCodeCamp** — parcours complets gratuits (JS, algo).

## Algorithmie et structures de données

- **NeetCode** (neetcode.io) — problèmes classiques d'entretien, bien expliqués.
- **Big-O Cheat Sheet** (bigocheatsheet.com) — référence des complexités.

## Comment utiliser ces ressources
1. **Ne les lis pas passivement.** Code en parallèle, teste chaque affirmation.
2. **Une ressource à la fois par sujet.** Le « tutorial hell » (accumuler des cours sans construire) est un piège.
3. **La doc officielle > les tutos tiers** pour la fiabilité.
4. **YouTube pour l'intuition, la doc pour la précision, le code pour l'ancrage.**
5. Quand une ressource et ce programme divergent, **privilégie la pratique** : construis, mesure, comprends.
