### Bilan

### Test pratique
Jalon démontrable : la suite adverse (15 cas hostiles du mois 9, adaptés) passe ; les erreurs (LLM down, doc corrompu, question vide) donnent des messages utilisateur propres ; les logs permettent de rejouer une session complète ; couverture de tests sur le cœur ≥ raisonnable (les chemins critiques).

### Test théorique
