## Revue hebdomadaire (jour 7)
- **Bilan :** Un projet non racontable n'existe pas pour un recruteur. Cette semaine : READMEs exemplaires, démo vidéo, et le storytelling écrit de CHAQUE projet de l'année.
- **Test pratique :** Livrables : README DocSense exemplaire (problème, démo GIF, archi, chiffres d'éval, install 5 min, limites) ; vidéo démo 3 min (écran + voix, scénario écrit) ; fiche storytelling par projet (contexte → décisions → résultats → apprentissages, 15 lignes chacune).
- **Test théorique :** Structure STAR pour raconter un projet ; les 5 questions qu'un recruteur se pose devant un repo GitHub ; pourquoi les chiffres d'éval de DocSense valent plus que 10 features.
- **Mini-projet :** Passe de polish GitHub : les 7 repos avec description, topics, README à jour, licence, et le profil GitHub avec un README de profil sobre.
- **Critères de passage :**
  - [ ] Tous les livrables faits
  - [ ] Un inconnu comprend DocSense en 3 min de README
  - [ ] Les fiches tiennent à l'oral (teste-les)
- **Exercice d'architecture :** Prépare le schéma d'architecture 'spécial entretien' de DocSense : une seule slide, lisible en 30 secondes, qui amorce 5 questions auxquelles tu sais répondre brillamment.
