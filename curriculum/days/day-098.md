## 🔁 Revue hebdomadaire

**Thème de la semaine :** React : composants, props, state, événements

### Bilan
Première semaine de React. Le modèle mental à acquérir : l'UI est une fonction de l'état.

### Test pratique
75 min : app Vite+React+TS — un compteur avancé (pas, min/max, reset), une liste de courses (ajout, suppression, case cochée), le tout typé proprement.

### Test théorique
Qu'est-ce qu'un composant ; props vs state ; pourquoi ne JAMAIS muter le state ; que déclenche setState ; qu'est-ce que le rendu conditionnel ; pourquoi une `key` sur les listes ?

### Mini-projet / livrable
'Kanban minimal' : 3 colonnes (à faire/en cours/fait), déplacer des cartes via boutons, état en mémoire.

### Checklist
- [ ] Je pense en composants (je découpe les maquettes)
- [ ] State minimal (je ne stocke pas ce qui se calcule)
- [ ] Aucune mutation directe
- [ ] Props typées

### Critères de passage à la semaine suivante
- [ ] Les 2 apps du test fonctionnent
- [ ] Kanban : déplacements corrects et state immuable
- [ ] Auto-éval React ≥ 2.5

Pour le Kanban : dessine l'arbre des composants et décide OÙ vit l'état (dans quelle branche). Explique pourquoi le remonter trop haut ou trop bas pose problème.
