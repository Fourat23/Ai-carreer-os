## 🎯 Objectif du jour
Comprendre le neurone et le gradient.

## 📖 Cours approfondi
**Modèle mental : un neurone est une machine à peser.** Il reçoit des entrées, les multiplie par des POIDS (l'importance apprise de chaque entrée), ajoute un BIAIS (un seuil de déclenchement), et passe le tout dans une ACTIVATION non linéaire : `sortie = σ(w·x + b)`. Apprendre = régler ces poids.

Pourquoi le coder en NumPy pur, sans framework ? Parce que c'est la seule façon de VOIR qu'il n'y a pas de magie : une multiplication, une addition, une fonction. La sigmoïde écrase le résultat entre 0 et 1 (une « probabilité »). L'erreur (loss) mesure l'écart entre la sortie et la cible. Et l'apprentissage (demain) consistera à tourner les poids dans le sens qui réduit cette erreur. Le ET logique est le terrain d'entraînement parfait : 4 exemples, 2 poids, 1 biais — tout se calcule à la main et se vérifie.

## 🧭 Exemple guidé
*Étudie ce pas-à-pas, puis FERME-le et attaque la pratique autonome de mémoire.*

**Énoncé** : un neurone qui apprend le ET logique.

**Raisonnement** : sortie attendue 1 seulement si x1 ET x2 valent 1 ; le neurone doit apprendre des poids qui rendent w·x + b fortement positif uniquement dans ce cas.

**Solution (squelette NumPy)** :
```python
import numpy as np
X = np.array([[0,0],[0,1],[1,0],[1,1]]); y = np.array([0,0,0,1])
w, b = np.random.randn(2), 0.0
sigmoide = lambda z: 1/(1+np.exp(-z))
for epoch in range(1000):
    pred = sigmoide(X @ w + b)          # 4 prédictions d'un coup
    erreur = pred - y                    # l'écart
    w -= 0.5 * (X.T @ erreur) / 4        # gradient (admis aujourd'hui)
    b -= 0.5 * erreur.mean()
print(np.round(pred, 2))                 # → [0. 0.05 0.05 0.93]
```

**Explication** : `X @ w` pèse les entrées ; l'erreur guide la correction des poids (le POURQUOI de cette formule = demain). **Variante** : essaie le OU logique (change y) — puis le XOR : constate l'échec (un neurone seul est une frontière DROITE ; le XOR exigera une couche cachée, jour 186).
