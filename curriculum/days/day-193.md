## 🎯 Objectif du jour
Vue d'ensemble d'un transformer.

## 📖 Cours approfondi
**Modèle mental : le transformer est une chaîne de raffinage du sens.** Le trajet complet d'une phrase : (1) **tokenisation** (jour 190) ; (2) **embeddings + position** — chaque token devient un vecteur, et comme l'attention traite tout en parallèle, il faut lui dire QUI EST OÙ (sans position, « chien mord homme » = « homme mord chien ») ; (3) **des dizaines de blocs** identiques : attention (les tokens se contextualisent mutuellement — jour 192) puis petit réseau feed-forward (chaque token digère ce qu'il a absorbé), avec des connexions résiduelles qui stabilisent le tout ; (4) **la sortie** : pour prédire la suite, le vecteur du dernier token est projeté sur TOUT le vocabulaire → un score par token possible → softmax → une distribution de probabilités ; (5) **l'échantillonnage** (température) choisit, on ajoute le token, on recommence.

Couche après couche, les représentations montent en abstraction : surface grammaticale d'abord, relations sémantiques ensuite. Rien dans cette chaîne ne « sait » ce qui est vrai — elle géométrise le plausible. Tu tiens ici l'explication MÉCANIQUE des hallucinations, deux semaines avant de les provoquer (jour 201).

## 🧭 Exemple guidé
*Étudie ce pas-à-pas, puis FERME-le et attaque la pratique autonome de mémoire.*

**Énoncé** : dessiner (à la main) le trajet de « Le chat dort » jusqu'au token suivant.

**Raisonnement** : un schéma par étape, flèches et légendes — c'est TON support d'entretien et le brouillon de ta note du jour 195.

**Trace attendue** :
```
[Le][chat][dort]                       ← tokens (3)
   ↓ embeddings + positions 1,2,3      ← 3 vecteurs « qui et où »
   ↓ ×N blocs [attention → feed-forward]
     (« dort » a absorbé « chat » : sommeil-de-chat)
   ↓ dernier vecteur → projection vocabulaire
   → { « paisiblement »: 21%, « profondément »: 14%, « . »: 11%, ... }
   → température 0 : « paisiblement »
```

**Explication** : chaque flèche de ton schéma doit répondre à « qu'est-ce qui entre, qu'est-ce qui sort ? ». **Variante** : ajoute sur le schéma OÙ interviennent la température (à l'échantillonnage) et la fenêtre de contexte (la longueur maximale de la ligne du haut).
