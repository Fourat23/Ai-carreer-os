## 🔁 Revue hebdomadaire

**Thème de la semaine :** JS : boucles, fonctions, tableaux, objets

### Bilan
La semaine où le code commence à 'faire des choses'. Le critère honnête : peux-tu écrire une boucle qui transforme un tableau sans regarder un exemple ?

### Test pratique
60 min, sans IA : écris 4 fonctions — `compterVoyelles(str)`, `sommePairs(arr)`, `inverserMots(phrase)`, `fusionnerContacts(arr1, arr2)` (dédoublonnés par email). Tests manuels dans le fichier.

### Test théorique
Explique par écrit : différence `for` / `for...of` / `while` ; passage par valeur vs référence ; qu'est-ce qu'un paramètre vs un argument ; pourquoi `[1,2] === [1,2]` est `false` ; que fait `arr.push` vs `arr.concat`.

### Mini-projet / livrable
'annuaire.js' : tableau d'objets contacts + fonctions rechercher/ajouter/supprimer/lister triés. Sans lib externe.

### Checklist
- [ ] Je manipule tableaux et objets imbriqués sans paniquer
- [ ] Je décompose un énoncé en étapes AVANT de coder
- [ ] Mes fonctions font une seule chose
- [ ] Commits quotidiens

### Critères de passage à la semaine suivante

### Exercice de réflexion architecturale
Prends `annuaire.js` et sépare-le en 2 fichiers : les données et les fonctions. Explique par écrit pourquoi cette séparation aide (2 paragraphes).
