# Prompt — Auditer le curriculum

Colle ceci après avoir lancé les scripts d'audit. Relis et corrige.

---

Voici la sortie des audits automatiques :

$ npm run curriculum:check
{COLLER LA SORTIE}

$ npm run curriculum:depth-check
{COLLER LA SORTIE}

Et voici un jour représentatif de la zone que je veux améliorer :
{COLLER LE CONTENU D'UN JOUR}

Analyse la qualité pédagogique de ce jour selon la définition d'un « jour qualitatif » (objectif, cours substantiel, modèle mental, exemple guidé, pratique autonome, quiz, correction exploitable, erreurs fréquentes, livrable, critères, lien futur, question d'entretien). Liste précisément :
1. ce qui manque ou est trop vague ;
2. les 3 améliorations à plus fort impact ;
3. quelles leçons de fond créer ou lier pour combler les manques.

Sois exigeant. Priorité : clarté et utilité pour un débutant, zéro remplissage.
