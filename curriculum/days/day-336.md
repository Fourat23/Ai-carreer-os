### Test pratique
Jalon démontrable : la suite adverse (15 cas hostiles du mois 9, adaptés) passe ; les erreurs (LLM down, doc corrompu, question vide) donnent des messages utilisateur propres ; les logs permettent de rejouer une session complète ; couverture de tests sur le cœur ≥ raisonnable (les chemins critiques).

### Test théorique

### Plan de remédiation (si un critère échoue)
- **Sécurité non maintenue** (suite adverse pas en CI) : une modification du polish a pu rouvrir une faille. Rejoue le jour 330 : suite adverse verte, intégrée à la CI (non-régression de sécurité).
- **App qui crashe** (chemins d'erreur non gérés) : c'est ce qui distingue un produit d'un prototype. Reprends le jour 331 : 10 scénarios d'erreur, dégradation gracieuse, testés EXPRÈS. BLOQUANT pour présenter le projet.
- **Pas de rapport qualité chiffré** : sans lui, tu ne peux pas PROUVER la valeur en entretien. Rejoue le jour 334 : trajectoire baseline → v1.0, 3 améliorations rentables, méthode reproductible.
- **Projet pas vraiment fini** (fonctionnalités encore en chantier) : le feature freeze est la discipline de livrer. Reprends le jour 335 : gèle, stabilise, purge la dette bloquante — un projet fini bat un projet ambitieux inachevé.
