## 🎯 Objectif du jour
Mesurer les stratégies.

## 📖 Cours approfondi
**Modèle mental : une comparaison de stratégies est une expérience contrôlée — une seule variable bouge, tout le reste est gelé.** Hier tu as construit le chunking structurel avec une HYPOTHÈSE (« les embeddings de sections sont plus nets ») ; aujourd'hui tu la soumets au verdict des chiffres. Le protocole est celui du jour 184 (les learning rates), transposé au retrieval :

1. **La variable** : la stratégie de chunking — taille fixe 400 tk (baseline), structurel (jour 240), et une troisième pour trianguler (taille fixe 200 tk, ou structurel avec re-découpe plus fine) : trois points valent mieux que deux pour voir une TENDANCE.
2. **Les constantes** : même corpus, même modèle d'embedding, même k, mêmes questions. Tes collections Chroma parallèles (jour 240) rendent ça trivial — trois index côte à côte, zéro ré-ingestion pendant la mesure.
3. **La métrique** : « le bon chunk est-il dans le top-3 ? » — décidable AUTOMATIQUEMENT grâce au champ `source_verite` de ton golden set (jour 237). Attention à la subtilité : les stratégies produisent des chunks DIFFÉRENTS — le verdict n'est pas « même chunk id » mais « un chunk du top-3 CONTIENT le passage de vérité » (recouvrement textuel avec la source de vérité).
4. **La lecture** : le score global décide, mais la lecture PAR TYPE de question explique. Le structurel peut gagner sur les factuelles (sections nettes) et perdre sur les synthèses (l'information répartie profite des chevauchements de la taille fixe). Un tableau croisé stratégie × type vaut dix moyennes.

Et la discipline d'interprétation : sur 30 questions, un écart de 1-2 réussites peut être du BRUIT. Regarde LESQUELLES ont basculé (gagnées vs perdues par le changement) — si le structurel gagne 5 questions et en perd 3, les 3 perdues sont la vraie information : elles disent ce que tu sacrifies.

## 🧭 Exemple guidé
*Étudie ce pas-à-pas, puis FERME-le et attaque la pratique autonome de mémoire.*

**Énoncé** : le tableau comparatif 3 stratégies × 30 questions, automatisé.

**Raisonnement** : écrire le verdict automatique d'abord (il servira tout le mois), boucler sur les collections ensuite, analyser par type enfin.

**Le verdict automatique** :
```python
def chunk_contient_verite(chunk_texte: str, verite: dict) -> bool:
    # verite = {"doc": "guide.md", "passage": "quatorze jours..."}
    # Recouvrement souple : le passage clé (normalisé) est dans le chunk
    return normaliser(verite["passage"]) in normaliser(chunk_texte)

def mesurer(collection, golden_set, k=3) -> dict:
    resultats = {}
    for q in golden_set["questions"]:
        if q["source_verite"] is None: continue      # hors corpus : pas ici
        top = collection.query(query_embeddings=[embed(q["question"])], n_results=k)
        resultats[q["id"]] = any(
            chunk_contient_verite(doc, q["source_verite"])
            for doc in top["documents"][0])
    return resultats
```

**Le tableau final** :
```
                    fixe-400   structurel   fixe-200
factuelles (12)       9/12       11/12        8/12
reformulées (6)       4/6         5/6         4/6
synthèse (6)          4/6         3/6         3/6   ← le structurel PERD ici
GLOBAL (24)          17/24       19/24       15/24
Questions basculées fixe-400 → structurel : +4 gagnées / -2 perdues
  → lire les 2 perdues : pourquoi ? (sections trop longues re-découpées ?)
```

**Explication** : le recouvrement textuel (plutôt que l'égalité d'ids) rend la mesure comparable ENTRE stratégies — c'est le point technique du jour. **Variante** : ajoute la colonne « rang moyen du bon chunk » (pas seulement dans/hors top-3) — une stratégie qui met la vérité au rang 4 est plus prometteuse qu'une qui la met au rang 15, et le reranking (jour 248) les départagera.

## 🎤 Question d'entretien
**« Comment compares-tu deux stratégies de chunking ? »** → Expérience contrôlée : même corpus, même embedding, même k, index parallèles ; golden set avec passage de vérité par question ; verdict automatique par recouvrement textuel (les chunks diffèrent entre stratégies, l'égalité d'id ne marche pas) ; lecture par TYPE de question, pas seulement en global — une stratégie gagne rarement partout, et les questions perdues disent ce qu'on sacrifie.
