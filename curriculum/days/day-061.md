## 🎯 Objectif du jour
Implémenter le socle : base SQLite + endpoints CRUD livres.

## 📖 Cours approfondi
**Concepts abordés :** Schéma · CRUD sur base · Couches · Paramétrage.

L'implémentation d'un socle suit un ordre précis : le schéma d'abord (init.sql exécutable — la base se reconstruit d'une commande), la couche data ensuite (toutes les requêtes paramétrées, isolées dans leur module), les routes enfin (traduction HTTP pure). Chaque étage se teste avant de monter le suivant.

Les statuts se choisissent avec précision dès maintenant : 201 + l'objet créé (avec son id) sur un POST réussi, 200 + l'objet sur un GET, 404 net sur un id inconnu, 400 détaillé sur une entrée invalide. Les corriger après coup casse les clients — les choisir bien d'emblée est gratuit.

Le réflexe pro : après chaque endpoint, LE tester immédiatement dans Postman (cas nominal + un cas d'erreur), pas « à la fin ».
