# Mois 1 — Fondations : terminal, Git, JavaScript, algorithmie

[← Vue d'ensemble](year-overview.md)

## Objectif du mois
Tu pars de quasi zéro : ce mois installe les fondations réelles — le terminal, Git, et surtout la programmation par la pratique en JavaScript (que tu connais un peu). Objectif : être capable d'écrire seul des petits programmes corrects, sans copier-coller.

## Semaines
- [Semaine 1](week-01.md) — Terminal, Git, premiers programmes JavaScript
- [Semaine 2](week-02.md) — JS : boucles, fonctions, tableaux, objets
- [Semaine 3](week-03.md) — Algorithmie : Big O, recherche, tris ; Git branches
- [Semaine 4](week-04.md) — Fonctions d'ordre supérieur, map/filter/reduce, intro récursion

## 🗓️ Revue mensuelle
- **Projet validant :** Mini-bilan : 5 katas algorithmiques résolus seul en 2h (fizzbuzz+, comptage de mots, max/min, palindrome, recherche dans un tableau) + un dépôt Git propre avec historique de commits quotidiens.
- **Score attendu en fin de mois :**
  - Algorithmie : 2/5
  - JavaScript / TypeScript : 2/5
  - Git / Linux : 2/5
- **Compétences acquises :**
  - Terminal et navigation fichiers
  - Git : init/add/commit/push/branch
  - JS : variables, conditions, boucles, fonctions, tableaux, objets
  - Décomposer un problème simple en étapes
- **Lacunes fréquentes à corriger :** Typiques à ce stade : confusion référence/valeur, off-by-one dans les boucles, peur du terminal. Les noter et les retravailler en semaine 5.
- **Livrable portfolio :** Dépôt GitHub 'katas-fondations' : 20+ exercices résolus, un README qui explique ta démarche.
- **Simulation d'entretien :** Simulation 20 min : explique à voix haute (enregistre-toi) ce qu'est une variable, une boucle, une fonction, et résous fizzbuzz en direct en commentant chaque ligne.
- **Exercice d'explication technique orale :** Explique Git (working directory / staging / commit / remote) à un débutant imaginaire en 5 minutes, sans notes.
