## 🎯 Objectif du jour
Connecter un front à TON API : fetch, états loading/error/data, module api réutilisable.

## 📖 Cours approfondi
**Concepts abordés :** fetch · useEffect · 3 états async · Module api.ts · Gestion d'erreur affichée.

useEffect synchronise ton composant avec l'EXTÉRIEUR (un fetch, un abonnement) : il s'exécute APRÈS le rendu, et son tableau de dépendances dit quand le rejouer. Le contrat des données async ne change pas : chaque fetch a TROIS états (loading, error, data) et l'UI doit décrire les trois — l'oublier donne les pages blanches et les spinners éternels.

En StrictMode (dev), React monte chaque composant DEUX fois exprès : si ton effet casse au double appel, c'est qu'il lui manque un cleanup ou qu'il n'est pas idempotent — c'est une feature de détection, pas un bug.

Le module api.ts unique (l'Adapter du jour 39) centralise les appels : types partagés avec le backend, gestion d'erreur commune, un seul endroit à modifier si l'API change. Un fetch dispersé dans chaque composant est le code smell frontend n°1.
