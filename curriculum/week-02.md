## Revue hebdomadaire (jour 7)
- **Bilan :** La semaine où le code commence à 'faire des choses'. Le critère honnête : peux-tu écrire une boucle qui transforme un tableau sans regarder un exemple ?
- **Test pratique :** 60 min, sans IA : écris 4 fonctions — `compterVoyelles(str)`, `sommePairs(arr)`, `inverserMots(phrase)`, `fusionnerContacts(arr1, arr2)` (dédoublonnés par email). Tests manuels dans le fichier.
- **Test théorique :** Explique par écrit : différence `for` / `for...of` / `while` ; passage par valeur vs référence ; qu'est-ce qu'un paramètre vs un argument ; pourquoi `[1,2] === [1,2]` est `false` ; que fait `arr.push` vs `arr.concat`.
- **Mini-projet :** 'annuaire.js' : tableau d'objets contacts + fonctions rechercher/ajouter/supprimer/lister triés. Sans lib externe.
- **Critères de passage :**
  - [ ] 4/4 fonctions du test pratique correctes
  - [ ] Explications théoriques justes (auto-corrigées avec la solution)
  - [ ] Auto-éval ≥ 3/5
- **Exercice d'architecture :** Prends `annuaire.js` et sépare-le en 2 fichiers : les données et les fonctions. Explique par écrit pourquoi cette séparation aide (2 paragraphes).
