## 🔁 Revue hebdomadaire

**Thème de la semaine :** Documentation, démo, storytelling des 7 projets

### Bilan
Un projet non racontable n'existe pas pour un recruteur. Cette semaine : READMEs exemplaires, démo vidéo, et le storytelling écrit de CHAQUE projet de l'année.

### Test pratique
Livrables : README DocSense exemplaire (problème, démo GIF, archi, chiffres d'éval, install 5 min, limites) ; vidéo démo 3 min (écran + voix, scénario écrit) ; fiche storytelling par projet (contexte → décisions → résultats → apprentissages, 15 lignes chacune).

### Test théorique
Structure STAR pour raconter un projet ; les 5 questions qu'un recruteur se pose devant un repo GitHub ; pourquoi les chiffres d'éval de DocSense valent plus que 10 features.

### Mini-projet / livrable
Passe de polish GitHub : les 7 repos avec description, topics, README à jour, licence, et le profil GitHub avec un README de profil sobre.

### Checklist

- [ ] Vidéo enregistrée en une prise fluide (répète avant)

### Critères de passage à la semaine suivante

### Plan de remédiation (si un critère échoue)
- **README qui ne vend pas** (commence par la stack, pas de chiffres) : c'est le document le plus rentable. Rejoue le jour 337 : problème d'abord, démo GIF, chiffres du rapport qualité, install 5 min.
- **Démo improvisée/qui bugue** : une démo qui hésite érode la confiance. Reprends le jour 338 : scénario écrit, répété, plusieurs prises jusqu'à une fluide.
- **Projets listés sans storytelling** : « j'ai fait un RAG » est oubliable. Rejoue le jour 339 : contexte → décisions → résultats → apprentissages, format STAR prêt pour l'entretien.
- **Portfolio incohérent** (test des 3 minutes échoué) : le recruteur voit l'ensemble. Reprends le jour 342 : message aligné, parcours fluide, un inconnu comprend en 3 minutes. BLOQUANT avant de candidater — un portfolio confus fait perdre des opportunités.

### Questions d'entretien de la semaine
1. **« À quoi ressemble un bon README ? »** Attendu : problème et valeur d'abord (pas la stack), démo visuelle, chiffres d'éval, install 5 min, limites honnêtes ; le README est l'interface avec le marché.
2. **« Montre-moi ton projet. »** Attendu : démo de 3 min scénarisée et fluide (confiance : citations/refus ; valeur : analyse), qui MONTRE que ça marche.
3. **« Parle-moi d'un projet. »** Attendu : storytelling contexte → décisions (avec pourquoi) → résultats chiffrés → apprentissages (format STAR).
4. **« Présente l'architecture de ton projet. »** Attendu : schéma clair lisible en 30s, qui amorce les questions maîtrisées (hybride, éval, sécurité), réponses préparées.
