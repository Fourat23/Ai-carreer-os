> Une revue ne « se corrige » pas : elle s'ÉVALUE. Voici l'attendu, la grille et les critères de passage.

## 🎯 Attendu de la semaine
Thème : **Documentation, démo, storytelling des 7 projets**. Un projet non racontable n'existe pas pour un recruteur. Cette semaine : READMEs exemplaires, démo vidéo, et le storytelling écrit de CHAQUE projet de l'année.

## ✅ Grille d'évaluation (note chaque axe de 0 à 5)
- **Test pratique réussi** dans le temps imparti : Livrables : README DocSense exemplaire (problème, démo GIF, archi, chiffres d'éval, install 5 min, limites) ; vidéo démo 3 min (écran + voix, scénario écrit) ; fiche storytelling par projet (contexte → décisions → résultats → apprentissages, 15 lignes chacune).
- **Test théorique** (réponds de mémoire puis auto-corrige) : Structure STAR pour raconter un projet ; les 5 questions qu'un recruteur se pose devant un repo GitHub ; pourquoi les chiffres d'éval de DocSense valent plus que 10 features.
- **Mini-projet / livrable** conforme : Passe de polish GitHub : les 7 repos avec description, topics, README à jour, licence, et le profil GitHub avec un README de profil sobre.
- **Exercice d'architecture** fait sérieusement : Prépare le schéma d'architecture 'spécial entretien' de DocSense : une seule slide, lisible en 30 secondes, qui amorce 5 questions auxquelles tu sais répondre brillamment.

## 📋 Checklist de validation
- [ ] README DocSense relu par quelqu'un (ou à voix haute)
- [ ] Vidéo enregistrée en une prise fluide (répète avant)
- [ ] 7 fiches storytelling écrites
- [ ] Profil GitHub propre

## 🚦 Critères de passage à la semaine suivante
- [ ] Tous les livrables faits
- [ ] Un inconnu comprend DocSense en 3 min de README
- [ ] Les fiches tiennent à l'oral (teste-les)

## ⚠️ Erreurs fréquentes en revue
- Se sur-noter (familiarité ≠ maîtrise) : ne compte que ce que tu produis SEUL et sais EXPLIQUER.
- Bâcler le test théorique en le relisant au lieu de répondre de mémoire (rappel actif).
- Avancer malgré des critères non atteints : mieux vaut consolider 2-3 jours que bâtir sur du sable.
- Oublier de mettre à jour ses scores de compétences dans l'application.
