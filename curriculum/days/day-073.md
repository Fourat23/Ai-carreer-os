## 🎯 Objectif
Maîtriser rebase, squash, historique lisible, et le workflow de collaboration (même en solo).

## 📚 Concepts
- rebase vs merge
- Squash de commits
- Historique lisible
- Pull requests (concept)
- Résolution de conflits en rebase

## ✍️ Exercice principal
Sur un projet : crée une branche de feature avec 5 commits brouillons, puis nettoie l'historique (rebase interactif : squash, reword) pour obtenir 2 commits propres. Simule une PR (description, checklist).

## 📦 Livrable attendu
Un historique nettoyé par rebase + une description de PR type.

## 🔗 Ressources
- git-scm.com/book — rebasing ; learngitbranching (niveaux avancés)

## 🤖 Règle d'utilisation de l'IA
**D'abord sans IA.** Tente seul au moins 30 minutes avant toute aide. Ne copie-colle jamais une réponse d'IA : lis, ferme, réécris de mémoire.

Manipule Git seul : la peur du rebase disparaît par la pratique.

- Comment j'expliquerais ce concept en entretien ?
- Où réutiliserai-je ça dans un projet ?
