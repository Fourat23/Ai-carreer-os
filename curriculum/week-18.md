- **Mini-projet :** CLI Python 'notes' : ajouter/lister/chercher des notes stockées en JSON, avec argparse.
- **Critères de passage :**
  - [ ] 5/5 exercices transposés corrects
  - [ ] CLI notes fonctionnel
  - [ ] Auto-éval python ≥ 2
- **Exercice d'architecture :** Compare l'organisation d'un projet Python (modules, __init__, scripts) avec ce que tu faisais en Node. Écris tes 5 conventions personnelles pour tes futurs projets Python.
