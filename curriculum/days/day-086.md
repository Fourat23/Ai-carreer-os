## 🎯 Objectif du jour
Préparer le récit de LivreAPI pour CV/entretien : ce qu'il prouve, les décisions, les difficultés.

## 📖 Cours approfondi
**Concepts abordés :** Storytelling de projet (STAR) · Ce que le projet prouve · Décisions et trade-offs · Fiche projet.

Un projet non racontable n'existe pas pour un recruteur. Le format STAR structure le récit : SITUATION (le problème et pour qui), TÂCHE (ce qu'il fallait accomplir), ACTION (tes décisions — c'est là que les ADRs brillent : « j'ai choisi X plutôt que Y parce que... »), RÉSULTAT (chiffré et démontrable).

L'erreur classique : raconter les FEATURES (« mon API fait du CRUD et de la recherche ») au lieu des DÉCISIONS (« j'ai dû arbitrer entre valider à la main ou avec une librairie — voici mon raisonnement »). Les features montrent ce que tu as tapé ; les décisions montrent comment tu PENSES. On recrute la pensée.

La difficulté surmontée est l'or du récit : un vrai obstacle (la transaction d'emprunt, le bug de référence) + ta démarche pour le résoudre = la preuve vivante de ta valeur. Prépare-la, répète-la à voix haute, chronomètre 5 minutes.
