## 🎯 Objectif du jour
Implémenter Stack (LIFO) et Queue (FIFO) génériques, comprendre leurs coûts O(1), les appliquer.

## 📖 Cours approfondi
**Concepts abordés :** LIFO / FIFO · Opérations O(1) · Classe générique · Applications : undo, parenthèses, files.

Une Stack (pile) est LIFO : dernier entré, premier sorti — comme une pile d'assiettes. Une Queue (file) est FIFO : premier entré, premier sorti — comme une file d'attente. Les deux offrent des opérations O(1) aux extrémités.

Cas d'usage réels : la Stack porte l'historique undo/redo, la call stack de la récursion, la vérification de parenthèses ; la Queue porte les files de traitement, le BFS, les files de messages (mois 10).

En TypeScript, la classe générique `Stack<T>` fonctionne pour tout type sans perdre le typage : c'est exactement le cas d'usage des génériques vus au jour 37.

## ⚠️ Erreurs fréquentes
- Queue avec shift() = O(n) sur gros volumes (mentionner la version à deux index).
- Oublier le cas 'ouvrantes en trop' (pile non vide à la fin).
