# Correction — Jour 342 : Relecture et cohérence du portfolio

[← Retour au jour 342](../days/day-342.md)

> ⛔ **Ne lis cette correction qu'après avoir vraiment tenté seul.** Une correction n'est pas une réponse à copier : c'est un outil pour comprendre ta démarche.

## 🧠 La logique attendue
Solution simple : vérifier que chaque pièce est bonne. Solution améliorée : vérifier la COHÉRENCE de l'ensemble — message aligné (tous les supports racontent la même histoire), parcours du visiteur fluide (profil → projet → démo → install, sans lien mort), et le test des 3 minutes avec un regard neuf (un inconnu comprend quoi/valeur/qui sans toi). Le recruteur voit l'ensemble ; la cohérence globale transforme des pièces séparées en une candidature convaincante.

## ⚠️ Erreurs probables et points à vérifier
- Vérifier chaque pièce isolément mais pas l'ensemble : des pièces excellentes mais incohérentes diluent l'impact — vérifier la cohérence globale.
- Liens morts / impasses dans le parcours : un lien mort casse le parcours et signale la négligence — vérifier chaque lien.
- Message dispersé (GitHub dit X, CV dit Y) : le recruteur est confus — aligner tous les supports sur une histoire nette.
- Sauter le test du regard neuf : TU comprends ton portfolio ; le test révèle ce qui n'est clair que pour toi.

## 🔍 Comment vérifier ta solution
- Tous les supports racontent la même histoire (message cohérent).
- Le parcours du visiteur est fluide (profil → projet → démo → install).
- Aucun lien mort ni impasse.
- Le test des 3 minutes est passé (un inconnu comprend quoi/valeur/qui).
- Chaque lien du portfolio est vérifié vivant (variante).

## 🎤 À savoir expliquer à l'oral
Explique la cohérence comme contrôle qualité final : « le recruteur voit l'ENSEMBLE de mon portfolio, pas une pièce isolée — je vérifie que profil, README, démo et fiches racontent la même histoire, que le parcours est fluide sans lien mort, et qu'un inconnu comprend mon projet et ma valeur en 3 minutes sans moi ». La cohérence globale transforme des pièces séparées en une candidature qui retient l'attention.
