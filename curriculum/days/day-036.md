## 🎯 Objectif
Installer TS, comprendre pourquoi typer, annoter les types de base, lire les erreurs du compilateur comme des alliées.

## 📚 Concepts
- tsc / tsconfig
- Types primitifs
- Inférence
- any (à fuir) vs unknown
- strict mode

## ✍️ Exercice principal
Convertis 3 fichiers JS du mois 1 (convertisseur, validateur, requetes) en TS strict : zéro any, zéro erreur tsc. Note chaque bug que le typage RÉVÈLE.

## 📦 Livrable attendu
ts/ : 3 fichiers .ts compilant en strict + notes sur les bugs révélés.

## 🔗 Ressources

## 🤖 Règle d'utilisation de l'IA
