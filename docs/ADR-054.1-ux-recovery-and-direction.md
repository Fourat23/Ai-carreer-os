# ADR-054.1 — UX Recovery & Visual Direction (contrat)

- **Statut** : accepté (V54.1).
- **Contexte** : après V54, l'audit CP0 (captures réelles) montrait un calendrier
  visuellement cassé (semaines wrappées, gros trous entre mois), une navigation
  bruyante (6 labs au 1er niveau), un Parcours « catalogue SaaS » (CTA répétés),
  une Synthèse en 8 cartes clonées, et des pages clairsemées. Priorité : verrouiller
  une direction visuelle réellement meilleure AVANT toute migration large.

## Principes visuels (contrat)
- **Dark premium, sobre, dense mais respirable.** Esprit Linear / GitHub / IDE.
- **Accent indigo/violet réservé** à identité, action, focus, actif. **Vert `--ok`**
  réservé au succès/validation. La couleur n'est **jamais** le seul signal d'état
  (toujours libellé + point/icône).
- **Élévation** : `--bg < --panel < --panel-2 < --raised` + ombres discrètes
  (`--shadow-1/-2/-focus`). Pas de glow, pas de gradient gadget.
- **Hiérarchie de lecture** : contexte → état → raison → action → détail.

## « A card is not the default layout primitive »
Choisir la primitive selon l'intention, PAS la carte par défaut :
- **PrimaryFocus** — un unique bloc dominant « quoi faire maintenant » (cockpit).
- **Panel** — surface calme titrée (rail, encarts) ; `is-emphasis` = primaire.
- **ListRow / StructuredList** — listes denses scannables (missions, parcours,
  révisions). Préférer une liste 1 colonne à une grille de cartes clonées.
- **table / matrix** — comparaison multi-dimensionnelle (Synthèse) ; scroll/colonnes
  masquées en responsive, jamais d'overflow document.
- **Status** — état sémantique (ton + libellé + point).
- **Metric** — donnée de pilotage réelle (jamais vanity).
- **SectionHeader / PageHeader** — structure éditoriale.
- **EmptyState / InlineNotice** — vide honnête + explication du mécanisme (jamais du
  remplissage décoratif).
- **Calendrier** — mois (panneaux) en maçonnerie de colonnes ; semaine = grille fixe
  de 7 jours ; couverture annoncée (transparence du filtre parcours).

## Navigation (IA)
Pilotage / Apprendre / Évaluer / Outils au 1er niveau. Les surfaces spécialisées
(Laboratoires, Carrière, Méthode) sont **repliables** (moins de bruit), sans
supprimer aucune route ni changer d'URL. État actif = teinte accent + icône + barre.

## Invariants
Curriculum 1.0 gelé ; corpus SHA-1 `4c1f3028…` ; `progress.json` `32360402…` ;
une consultation ne mute jamais la progression (P0 V54, gardé) ; une seule source de
vérité ; anti-gamification ; anti-AI-slop ; données 100 % réelles.

## Calendrier — contrat vérifiable
`lib/calendar-model.mjs` (`buildCalendar`) expose expectedDays / renderedDays /
missing / duplicates / ordered / weekOrder / monthOrder / weekSpan. Tests
`tests/v541-calendar.test.mjs` interdisent toute disparition de jour, doublon,
inversion, semaine incohérente. **Aucun jour perdu silencieusement.**
