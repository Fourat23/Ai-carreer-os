**Thème de la semaine :** Classification : arbres, forêts, cross-validation, overfitting

### Bilan
Le cœur du ML classique : arbres, random forest, validation croisée, et le concept le plus important de tout le ML : l'overfitting.

### Test pratique
90 min : dataset de classification déséquilibré fourni — arbre de décision (visualisé), random forest, cross-validation 5 folds, courbe d'apprentissage, matrice de confusion commentée, choix de métrique justifié (pas accuracy !).

### Test théorique
Comment un arbre décide d'un split ; pourquoi une forêt bat un arbre ; overfitting/underfitting : symptômes et remèdes ; que montre une matrice de confusion ; pourquoi accuracy ment sur du déséquilibré ?

### Questions d'entretien de la semaine
1. **« Pourquoi l'accuracy trompe-t-elle sur classes déséquilibrées ? »** Attendu : prédire la classe majoritaire donne une accuracy élevée sans utilité ; précision/rappel selon le coût des erreurs, seuil réglé.
2. **« Comment un arbre surapprend-il ? »** Attendu : trop profond, il mémorise (train ≈ 1, test bas) ; profondeur = curseur ; arbre instable.
3. **« Pourquoi une forêt bat-elle un arbre ? »** Attendu : bagging + hasard des features décorrèlent les arbres, le vote annule leurs erreurs (sagesse des foules) ; robustesse contre interprétabilité.
4. **« Pourquoi la validation croisée plutôt qu'un split ? »** Attendu : un split dépend du hasard du découpage ; la CV donne moyenne ± variabilité ; préprocessing dans un Pipeline (anti-leakage).
5. **« Qu'est-ce que l'overfitting et comment le corriges-tu ? »** Attendu : apprendre le bruit, écart train/validation, biais-variance, régularisation/simplification/plus de données, mesure sur la validation.
6. **« Comment améliorerais-tu ce modèle ? »** Attendu : analyse d'erreurs qualitative — regarder les erreurs, trouver des patterns, agir ciblé (feature, labels, données).
