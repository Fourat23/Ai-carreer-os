### Questions d'entretien de la semaine
1. **« Pourquoi le feature engineering est-il si important ? »** Attendu : un modèle ne voit que ses features ; de bonnes features (ratios, agrégats, dates) battent souvent un meilleur modèle ; chaque feature une hypothèse mesurée, sans leakage.
2. **« One-hot vs label encoding ? »** Attendu : one-hot pour le non-ordonné (pas d'ordre fictif), label seulement pour l'ordonné ; normaliser pour les modèles à base de distance.
3. **« Pourquoi un Pipeline ? »** Attendu : anti-leakage par construction (préprocessing ré-appris à chaque fold), reproductible et déployable, se comporte comme un modèle unique.
4. **« Comment mènes-tu un clustering ? »** Attendu : non supervisé, normaliser, choisir k (coude + silhouette), INTERPRÉTER les clusters en segments métier.
5. **« Comment expliques-tu un modèle ? »** Attendu : permutation importance (validation, agnostique) vs native (biaisée) ; SHAP pour l'individuel ; une feature trop importante révèle un leakage.
6. **« Comment cadres-tu un projet ML ? »** Attendu : décision métier → cible précise → métrique selon le coût → baseline et succès fixés avant → pièges anticipés.
