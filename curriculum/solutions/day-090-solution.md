## ⚠️ Erreurs probables et points à vérifier
- Négliger de rendre les projets vraiment propres : un recruteur peut regarder MAINTENANT, un projet à 90 % vaut moins qu'un projet fini.
- Aborder la data sans consolider les fondations : accumulation de lacunes.
- Autosatisfaction qui freine : le bilan célèbre pour relancer, pas pour s'arrêter.
- Voir la data/IA comme une rupture effrayante au lieu d'une continuité (le RAG s'appuie sur des briques connues).

## 🔍 Comment vérifier ta solution
- Bilan écrit avec relecture du jour 1 et lettre au soi du jour 1.
- Les scores réévalués + 3 lacunes/priorités avec plan daté.
- Les 2 projets GitHub inspectés une dernière fois (un recruteur peut regarder aujourd'hui).
- La projection data/ML relie explicitement les mois à venir aux fondations acquises.

## ❓ Réponses du mini-quiz
1. **Qu'es-tu devenu en 90 jours, et est-ce employable ?**
   → Un développeur full-stack junior : terminal, Git, algorithmique, structures, TypeScript, API REST sécurisée et testée, SQL, React branché sur ton backend. C'est déjà un profil employable sur des rôles full-stack juniors.
2. **Pourquoi rendre les 2 projets « vraiment propres » avant de passer à la data ?**
   → Parce qu'ils sont ta preuve ACTUELLE : un recruteur peut les regarder maintenant. Un projet à 90 % non fini vaut moins qu'un projet fini ; la finition (README, tests, sécurité) les rend crédibles.
3. **En quoi la data/IA s'appuie-t-elle sur les fondations acquises ?**
   → Elle ne repart pas de zéro : la data manipule des données comme les tables SQL, le ML est un processus rigoureux comme les tests, et le RAG combine ingestion + API + évaluation — trois compétences déjà acquises. C'est une continuité, pas une rupture.
4. **Qu'est-ce qui te différenciera d'un full-stack junior classique ?**
   → L'IA appliquée (mois 7-12), construite sur les fondations full-stack. C'est ce qui rend « bankable IA » : un développeur qui sait aussi construire des systèmes d'IA, pas seulement des applications web classiques.

## 🎤 À savoir expliquer à l'oral
Acte la transformation de nature : « en 90 jours, de quelques notions de JS à un profil full-stack junior employable, avec 2 projets démontrables ». Montre que tes projets sont une preuve propre inspectable aujourd'hui. Surtout, projette la suite comme une CONTINUITÉ : « le RAG, c'est de l'ingestion + une API + de l'évaluation — je sais déjà les trois ». Conclure sur l'objectif « bankable IA » (logiciel solide + IA, un profil rare) montre une vision de carrière claire, exactement ce qui rassure un recruteur sur ta trajectoire.
