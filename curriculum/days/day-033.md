## 🎯 Objectif
Implémenter Stack (LIFO) et Queue (FIFO) génériques, comprendre leurs coûts O(1), les appliquer.

## 📚 Concepts
- LIFO / FIFO
- Opérations O(1)
- Classe générique
- Applications : undo, parenthèses, files

## ✍️ Exercice principal
`Stack<T>` et `Queue<T>` (push/pop/peek/isEmpty/size). Puis `parenthesesValides(str)` gérant (), [], {} avec ta Stack, et une file de tâches FIFO.
