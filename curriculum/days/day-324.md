## 📖 Cours approfondi
**Modèle mental : la détection d'incohérences est l'analyse AVANCÉE de DocSense — elle ne traite plus un document isolé mais confronte un document au RESTE du corpus pour signaler les contradictions, avec le raisonnement visible dans les logs.** Après le workflow d'analyse d'un document (jour 323), tu construis une capacité plus sophistiquée : détecter quand un document CONTREDIT les autres (une valeur différente, une politique changée, une affirmation opposée). C'est une fonctionnalité à forte valeur qui exige de raisonner sur la COHÉRENCE SÉMANTIQUE entre sources — quelque chose qu'un diff textuel ne peut pas faire.

Ce qui rend la détection d'incohérences puissante et exigeante :
1. **La confrontation multi-documents** : pour un document donné, retrouver dans le corpus les passages qui traitent des mêmes sujets, puis comparer les affirmations — sont-elles cohérentes ou contradictoires ? C'est du raisonnement sémantique (une techno mentionnée différemment, un délai qui diffère), pas de la comparaison de chaînes. Tu as exploré ce cas au jour 276 (agent vérificateur) ; ici tu le construis comme une fonctionnalité de DocSense.
2. **Le workflow visible dans les logs** : le point d'observabilité (jour 297). Le raisonnement de détection (quels passages comparés, quelle contradiction trouvée) doit être TRAÇABLE — pour déboguer, pour auditer, et pour que l'utilisateur comprenne POURQUOI une incohérence est signalée. Un signalement d'incohérence sans justification traçable est inexploitable.
3. **La précision du signalement** : une incohérence signalée doit être RÉELLE (précision) — un faux signalement (« ces deux passages se contredisent » alors qu'ils sont cohérents) érode la confiance. Le format de sortie précise le document A, le document B, et la nature du conflit, vérifiable par l'utilisateur.

Pourquoi c'est une fonctionnalité à forte valeur : dans un corpus documentaire réel (specs, contrats, docs techniques), les incohérences s'accumulent silencieusement (une décision changée mais pas propagée partout) et causent des erreurs. Un outil qui les détecte fait un travail qu'aucun humain ne fait entièrement (trop fastidieux) et qu'aucun diff ne peut faire (il faut comprendre le SENS). C'est le genre de fonctionnalité qui transforme DocSense d'un « assistant de recherche » en un « gardien de la cohérence documentaire » — une valeur métier concrète et démontrable, avec le raisonnement visible qui la rend digne de confiance.

## 🧭 Exemple guidé
*Étudie ce pas-à-pas, puis FERME-le et attaque la pratique autonome de mémoire.*

**Énoncé** : la détection d'incohérences de DocSense (un document vs le corpus), workflow visible dans les logs.

**Exemple simple** : le cœur en une idée — pour chaque affirmation d'un document, retrouver les passages du corpus sur le même sujet et demander au LLM « ces affirmations sont-elles cohérentes ou contradictoires ? ». Le raisonnement est loggé.

**Raisonnement pas-à-pas** : extraire les affirmations, retrouver les passages liés dans le corpus, comparer par le LLM, signaler avec justification tracée.

**Implémentation** :
```python
def detecter_incoherences(doc: str) -> list[Incoherence]:
    affirmations = extraire_affirmations(doc)              # workflow, étape 1
    incoherences = []
    for aff in affirmations:
        passages_lies = retrieval(aff, corpus_sans(doc))  # même sujet ailleurs
        for p in passages_lies:
            verdict = comparer_llm(aff, p, temp=0)         # cohérent/contradictoire
            log("comparaison", aff=aff, passage=p, verdict=verdict)  # TRAÇABLE (j.297)
            if verdict.contradictoire:
                incoherences.append(Incoherence(doc_a=doc, doc_b=p.source,
                                                conflit=verdict.explication))
    return incoherences   # format : doc A / doc B / nature du conflit (vérifiable)
```

**Mini-quiz** : (a) Pourquoi un diff textuel ne suffit-il pas ? (b) Pourquoi le workflow doit-il être visible dans les logs ? (c) Que coûte un faux signalement d'incohérence ?
→ (a) il faut comprendre le SENS (une techno mentionnée différemment se contredit sans être un diff textuel) ; (b) pour déboguer, auditer, et que l'utilisateur comprenne POURQUOI c'est signalé ; (c) il érode la confiance — la précision du signalement est cruciale.

**Variante** : injecte volontairement une incohérence dans le corpus (change un délai dans un seul document) et vérifie que DocSense la détecte ET la justifie dans les logs — c'est ton test de rappel ET d'observabilité.

## 🏢 Cas métier
La détection d'incohérences documentaires répond à un vrai problème d'entreprise coûteux : dans un corpus de dizaines de documents (specs, runbooks, contrats), les contradictions s'installent silencieusement (une valeur changée à un endroit mais pas ailleurs) et causent des bugs, des erreurs de décision, des litiges. Un outil qui les signale — avec le raisonnement traçable qui les justifie — fait un travail qu'aucun humain ne fait entièrement et qu'aucun diff ne peut faire. Pour DocSense, c'est la fonctionnalité qui démontre une valeur métier concrète au-delà du RAG standard, et le raisonnement visible dans les logs la rend digne de confiance (l'utilisateur vérifie POURQUOI). « Mon assistant détecte les contradictions entre documents, avec le raisonnement traçable » est une démonstration de valeur qui marque en entretien.

## 🎤 Question d'entretien
**« Comment détecterais-tu des contradictions dans un corpus documentaire ? »** → Par du raisonnement sémantique, pas un diff : pour chaque affirmation d'un document, je retrouve les passages du corpus sur le même sujet (retrieval) et je demande au LLM s'ils sont cohérents ou contradictoires. Un diff textuel ne verrait pas qu'« on utilise Chroma » contredit « stockage JSON » — il faut comprendre le sens. Le raisonnement (passages comparés, contradiction trouvée) est TRAÇABLE dans les logs — pour déboguer, auditer, et que l'utilisateur comprenne pourquoi c'est signalé. Et je soigne la précision : un faux signalement érode la confiance. Le format précise document A, document B, nature du conflit — vérifiable.
