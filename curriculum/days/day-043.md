## 🎯 Objectif du jour
Consolider le style fonctionnel typé : fonctions pures typées, composition, immutabilité avec readonly.

## 📖 Cours approfondi
**Concepts abordés :** Fonctions pures typées · readonly / as const · compose/pipe typés · FP vs POO : le choix.

Typer les fonctions d'ordre supérieur révèle leur logique profonde : `compose<A, B, C>(f: (b: B) => C, g: (a: A) => B): (a: A) => C` dit exactement la contrainte de composition — la sortie de g doit nourrir l'entrée de f. Si les types ne s'emboîtent pas, la composition n'a pas de sens, et le compilateur le dit AVANT l'exécution.

`readonly` et `as const` font vérifier l'immutabilité (jour 26) par le compilateur : muter un `readonly string[]` est une erreur de compilation. La discipline devient un contrat outillé.

C'est le pattern général de TypeScript : transformer tes conventions (pureté, immutabilité, contrats) en règles VÉRIFIÉES mécaniquement.
