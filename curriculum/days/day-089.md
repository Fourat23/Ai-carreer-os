## 🎯 Objectif du jour
Assembler un mini full-stack complet (front React + LivreAPI) pour souder les acquis avant le mois 4.

## 📖 Cours approfondi
**Concepts abordés :** Full-stack assemblé · CRUD complet UI · États edge · Le flux complet compris.

Le full-stack assemblé est le moment de vérité : peux-tu suivre UNE donnée sur tout le trajet ? Clic « ajouter » → événement React → validation → fetch POST → route Express → service (règle métier) → requête SQL paramétrée → réponse 201 → mise à jour immuable du state → re-render. Si un maillon reste flou, c'est LÀ que tu dois creuser — la magie est interdite.

Les états EDGE font la différence : la liste vide (un message utile, pas une page blanche), l'erreur réseau (un message + possibilité de réessayer), le chargement (un indicateur). Un utilisateur passe 5% du temps dans ces états, mais c'est là que se joue la perception de qualité.

Ce mini full-stack est l'échauffement du projet 3 (BiblioApp, semaine 17) qui l'amènera au niveau portfolio : tests, GIF de démo, schéma d'architecture.
