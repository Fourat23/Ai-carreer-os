# V45 — LEARNER READINESS

Audit **lecture seule**. Répond à : « Puis-je commencer à apprendre avec AI Career OS aujourd'hui ? »
Critères explicites, sans auto-congratulation.

## Critères de readiness

- 🟢 **START NOW** : théorie stable + pratique de code exécutable + évaluation + progression cohérente.
  L'apprenant peut apprendre ET s'entraîner sans ressource externe.
- 🟠 **START WITH CAVEATS** : théorie stable + raisonnement/diagnostic, MAIS pratique de code absente
  ou SIMULÉE. L'apprenant comprend et raisonne, mais ne « fait » pas le geste technique ici.
- 🔴 **DO NOT START YET** : incomplet ou non disponible.

## Réponse directe à l'apprenant

**« Puis-je commencer aujourd'hui ? » → OUI, sur le tronc ingénierie logicielle.**

- **Commence maintenant (🟢)** : JavaScript/TypeScript → Frontend (React) OU Backend (HTTP/API/SQL) →
  Git/Linux → tests/qualité. Ce sont des parcours réellement APPRENABLES de bout en bout (théorie +
  pratique de code + évaluation + capstone).
- **Ordre recommandé** : fondations JS → algo/ds → TS → (frontend React **ou** backend HTTP/SQL) →
  tests/archi → capstone du domaine choisi.
- **Commence avec précautions (🟠)** : Cloud, Sécurité, Data/ML, IA appliquée. Tu y apprendras à
  COMPRENDRE et RAISONNER (leçons FORTES, assessments, défis de transfert, labs simulés, capstones),
  mais tu ne PRATIQUERAS pas le code de ces domaines dans la plateforme — prévois un environnement
  externe pour t'exercer.
- **Attends encore (🔴)** : deep learning comme compétence pratique ; le parcours annoncé
  `ai-fullstack-v1` (non disponible).

## Ce qui risque d'évoluer (à savoir avant de commencer)
- La PRATIQUE des domaines IA/cloud/sécurité/data est la priorité V46 : elle sera AJOUTÉE, sans
  invalider les leçons existantes (prose STABLE/BETA, cf. baseline).
- La readiness affichée dans l'app est un **PROXY structurel**, pas une certification de maîtrise.
