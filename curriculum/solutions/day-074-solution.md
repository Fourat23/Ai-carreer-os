## 🧠 La logique attendue
On documente pour un LECTEUR précis (recruteur, collègue, futur soi). Le README répond : c'est quoi, pourquoi, comment lancer, comment contribuer. L'ADR capture le POURQUOI d'une décision.

## ⚠️ Erreurs probables et points à vérifier
- Documenter ce que fait le code (visible) au lieu du pourquoi (invisible).
- README générique qui pourrait décrire n'importe quel projet.
