## 🎯 Objectif
Adopter une méthode de debug systématique : reproduire → isoler → hypothèse → prouver → corriger.

## 📚 Concepts
- Reproduire fiablement
- Bissection
- console.log stratégique / debugger
- Lire une stack trace
- Rubber duck

## ✍️ Exercice principal
Un programme à 5 bugs (fourni en correction : logique, typage, référence partagée, off-by-one, async). Trouve-les avec la MÉTHODE, en documentant symptôme→hypothèse→preuve→fix.

## 📦 Livrable attendu
Journal de debug des 5 bugs + ta méthode personnelle écrite.

## 🔗 Ressources
- Node --inspect / debugger VS Code

## 🤖 Règle d'utilisation de l'IA
**D'abord sans IA.** Tente seul au moins 30 minutes avant toute aide. Ne copie-colle jamais une réponse d'IA : lis, ferme, réécris de mémoire.

Débugue SEUL : demander la réponse court-circuite la compétence. Piste, pas solution.
