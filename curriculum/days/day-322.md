### Plan de remédiation (si un critère échoue)
- **Golden set faible** : c'est le socle de toute l'évaluation. Rejoue le jour 316 — dérive des cas d'usage de la SPEC, ancre dans le corpus réel, vérité-terrain avec passage exact.
- **Harnais non reproductible** : sans reproductibilité, les comparaisons de versions sont fausses. Reprends le jour 317 : température 0, golden versionné, config enregistrée.
- **Baseline mouvante ou unidimensionnelle** : c'est le point zéro de tout le mois. Rejoue le jour 319 : multidimensionnelle, immuable, rien corrigé pendant la mesure. BLOQUANT — sans baseline solide, aucune amélioration ne sera démontrable.
- **Docker qui ne tourne pas sur machine propre** : « ça marche chez moi » ne suffit pas. Reprends le jour 320 : teste git clone + docker compose up sur une machine/VM propre.
