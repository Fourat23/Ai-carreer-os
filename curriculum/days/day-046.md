## 🎯 Objectif du jour
Compléter le CRUD (done/rm/edit) et le filtrage/tri.

## 📖 Cours approfondi
**Concepts abordés :** CRUD complet · Filtres/tri · Immutabilité (jour 26) · Validation.

Le CRUD complet d'un vrai outil gère l'ÉTAT en style immuable : done/edit ne modifient pas la tâche, ils retournent une copie modifiée que le Store persiste (ton pattern mettreAJourParId du jour 26). Bénéfice concret : chaque opération est une fonction pure testable sans fichiers.

Les filtres combinables (--done --priority high) reprennent le pattern « filtre conditionnel » du jour 23 : chaque critère absent laisse tout passer. Attention au piège falsy : un filtre « priorité 0 » ou une chaîne vide ne doit pas être confondu avec « pas de filtre ».

La validation aux frontières : tout argument CLI est hostile jusqu'à preuve du contraire (id non numérique, priorité inconnue → message clair, exit 1).
