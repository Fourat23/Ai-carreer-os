# Grille de compétences (scorecard 0-5)

20 compétences, évaluées de 0 à 5. À réévaluer honnêtement à chaque revue mensuelle et lors des bilans (jours 30, 60, 90, 180, 270, 365).

## Échelle générique (0-5)
| Niveau | Signification |
|---|---|
| **0** | Jamais pratiqué. |
| **1** | Notions : je reconnais les concepts, je ne produis rien seul. |
| **2** | Guidé : je produis avec un tutoriel ou de l'aide. |
| **3** | Autonome sur cas standard : je produis seul un résultat correct. |
| **4** | Solide : je gère les cas non triviaux, je debugge, j'explique mes choix. |
| **5** | Employable+ : je conçois, je justifie les trade-offs, je peux l'enseigner. |

> **Cible pour candidater :** la plupart des compétences cœur à **3-4**, les compétences IA (LLM, RAG, évaluation) à **3+**, et 2-3 compétences « signature » à **4-5**.

## Les 20 compétences et ce que « 3 » puis « 5 » signifient concrètement

### Fondations
- **Algorithmie** — *3* : je résous des katas standards seul avec la méthode. *5* : je conçois, j'analyse la complexité, j'optimise et j'explique.
- **Structures de données** — *3* : j'utilise la bonne structure au bon moment. *5* : je les implémente, je justifie les trade-offs (temps/mémoire).
- **JavaScript / TypeScript** — *3* : j'écris du TS typé propre. *5* : génériques, types avancés, code idiomatique et maintenable.
- **Python** — *3* : je code proprement en Python (pandas). *5* : idiomatique, testé, packagé.
- **Git / Linux** — *3* : branches, merges, terminal au quotidien. *5* : rebase, scripts, workflow d'équipe, résolution sereine de conflits.

### Web & data
- **HTTP / API** — *3* : je conçois et consomme une API REST correcte. *5* : design robuste, versionnement, sécurité, performance.
- **SQL / Data** — *3* : JOIN, agrégats, schéma simple. *5* : modélisation, index, transactions, requêtes analytiques.

### Software engineering
- **Software engineering** — *3* : code lisible, testé, débuggé méthodiquement. *5* : refactoring, TDD, revue de code, qualité systématique.
- **Architecture** — *3* : je structure en couches (3-tiers). *5* : hexagonale, trade-offs, design système à l'oral.
- **Design patterns** — *3* : je reconnais et applique les patterns courants. *5* : je choisis à bon escient et j'évite la sur-ingénierie.

### IA / ML
- **Machine learning** — *3* : workflow ML honnête (baseline, métriques, anti-leakage). *5* : feature engineering, interprétabilité, mise en service.
- **Deep learning** — *3* : j'entraîne un MLP et j'explique un transformer. *5* : je fine-tune, je diagnostique, je conçois une architecture.
- **LLM** — *3* : intégration robuste (prompts, structured outputs, function calling). *5* : optimisation coût/qualité, patterns avancés, à l'échelle.
- **RAG** — *3* : pipeline complet compris et fonctionnel. *5* : hybride, reranking, mesuré, à l'échelle.
- **Agents** — *3* : je code un agent simple et je sais quand ne PAS en faire. *5* : orchestration fiable, workflows vs agents maîtrisés.
- **Évaluation IA** — *3* : golden set + LLM-as-judge fonctionnels. *5* : protocoles rigoureux, calibration, dashboard qualité.

### Transverses
- **Sécurité** — *3* : je valide, je gère les secrets, je connais l'OWASP de base. *5* : threat modeling, défense en profondeur, sécurité IA.
- **Cloud / DevOps** — *3* : Docker, variables d'environnement, CI simple. *5* : déploiement, observabilité, coûts, résilience.
- **Communication technique** — *3* : README clairs, je présente un projet. *5* : storytelling, explication d'arbitrages, entretien architecture.
- **Autonomie projet** — *3* : je mène un projet cadré jusqu'au bout. *5* : je cadre, je découpe, j'arbitre le scope, je livre en qualité.

## Comment t'auto-évaluer honnêtement
1. Pour chaque compétence, demande : **« Puis-je le faire SEUL, sans IA, sur un cas non trivial ? »** Si non → maximum 2.
2. **« Puis-je l'expliquer en entretien ? »** Si non → maximum 3.
3. Le piège de l'ego : on se sur-note après avoir *vu* un concept. Ne compte que ce que tu peux *produire*.
4. Note dans l'app à chaque revue mensuelle. La courbe de progression compte plus que la valeur absolue.
